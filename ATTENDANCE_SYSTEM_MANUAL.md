## 1. System Overview

The Control Personal Campo system is a comprehensive worker attendance management solution designed for construction sites and field operations. It combines QR code scanning, GPS verification, and real-time data synchronization to ensure accurate attendance tracking.

### Key Features
- **QR Code Scanning**: Fast worker identification using generated ID cards
- **GPS Verification**: Location-based attendance validation
- **Offline Capability**: Works without internet connection, syncs when reconnected
- **Real-time Dashboard**: Live view of worker status and attendance patterns
- **Multiple Attendance Types**: Entry, break departure, break return, and exit marking

### Attendance Types Explained
1. **Entrada (Entry)**: Worker arrives at the work site
2. **Salida Receso (Break Departure)**: Worker leaves for scheduled break
3. **Regreso Receso (Break Return)**: Worker returns from break
4. **Salida Obra (Site Exit)**: Worker leaves the work site for the day

## 3. Initial Setup

### 3.1 System Configuration

#### Step 1: Configure Google Apps Script Connection
1. Navigate to **Ajustes** (Settings) and open the Google Sheets connection assistant.
2. Create/deploy the Apps Script Web App once using the code shown by the assistant.
3. Set the Web App to execute as the owner and allow access to anyone who has the link.
4. Paste the URL ending in `/exec`.
5. Click **Preparar Google Sheets automáticamente**.
6. The application will create or recover the spreadsheet, create the `Personal`, `Asistencias`, `Alertas` and `Configuracion` sheets, and verify read access.
7. If successful, click **Finalizar Configuración**. The URL is stored locally in the browser.

The application never asks for or stores a Google password. Google handles authorization in its own interface. After the first deployment, no manual spreadsheet creation or sheet naming is required.

#### Step 2: Configure Work Schedule
1. In **Ajustes**, locate the **Horarios de Obra** section
2. Set the following times according to your work schedule:
   - **Entrada** (Entry): Default 07:00
   - **Salida Receso** (Break Departure): Default 10:00
   - **Regreso Receso** (Break Return): Default 10:30
   - **Salida Obra** (Site Exit): Default 17:00
3. Click **Guardar Horarios** (Save Schedule)

#### Step 3: Configure GPS Settings (Optional but Recommended)
1. In **Ajustes**, locate the **GPS y Geocercas** section
2. Enable **Habilitar GPS en marcaciones** (Enable GPS in attendance)
3. Optionally enable **Requerir ubicación obligatoria** (Require mandatory location)
4. Set the work site center coordinates:
   - Click the crosshair button to capture current location
   - Or manually enter latitude and longitude
5. Set the **Radio de Geocerca** (Geofence Radius) in meters (default: 200m)
6. Click **Guardar Configuración GPS** (Save GPS Configuration)

### 3.2 Worker Registration

#### Step 1: Add New Worker
1. Navigate to **Personal** (Workers) in the main menu
2. Click **Nuevo Trabajador** (New Worker)
3. Fill in the required information:
   - **Nombre Completo** (Full Name) - Required
   - **DPI / CUI** (ID Number) - Required (13 digits for Guatemala)
   - **Puesto de Trabajo** (Job Position) - Required
   - **Jefe Inmediato** (Immediate Supervisor) - Optional
   - **Teléfono Móvil** (Mobile Phone) - Optional
   - **WhatsApp** - Optional
   - **Dirección** (Address) - Optional
4. Add worker photo:
   - Click **Tomar Foto** (Take Photo) to use device camera
   - Or click **Subir Foto** (Upload Photo) to select from gallery
5. Click **Guardar Trabajador** (Save Worker)

#### Step 2: Generate QR Code ID Card
1. In the worker list, locate the newly added worker
2. Click the QR icon in the actions column
3. Review the generated ID card
4. Click **Imprimir Carné** (Print ID Card) or **Descargar PNG** (Download PNG)
5. Distribute the physical ID card to the worker

## 4. Daily Attendance Workflow

### 4.1 Morning Preparation

#### Before Workers Arrive
1. **System Check**: Ensure the device is charged and connected to internet
2. **Connection Verification**: Check the connection status in the sidebar
   - Green dot: Connected to Google Sheets
   - Red dot: No connection (offline mode active)
   - Yellow dot: Attempting to connect
3. **GPS Verification**: If using GPS, ensure location services are enabled
4. **Camera Check**: Test that the camera is working for QR scanning

#### Opening the Attendance System
1. Launch the Control Personal Campo application
2. Navigate to **Asistencia** (Attendance) in the main menu
3. Verify the current date displayed is correct
4. Ensure the **Escáner QR** (QR Scanner) tab is selected

### 4.2 Worker Arrival Process

#### Standard Entry Process
1. **Worker Presentation**: Worker presents their QR code ID card
2. **QR Scanning**: 
   - Hold the device camera approximately 15-20cm from the QR code
   - Ensure good lighting and focus
   - Wait for the system to recognize the QR code
3. **Worker Verification**: 
   - System displays worker's photo, name, and position
   - Verify the worker identity matches the displayed information
4. **Attendance Marking**:
   - Click the **Entrada** (Entry) button
   - System captures GPS location (if enabled)
   - System records timestamp and attendance type
5. **Confirmation**: 
   - System displays success message with timestamp
   - Audio confirmation (beep) sounds
   - Device may vibrate (if supported)

#### Manual Entry Process (if QR unavailable)
1. Click the **Marcación Manual** (Manual Marking) tab
2. In the search field, type the worker's name or ID number
3. Select the worker from the autocomplete list
4. Verify worker information displayed
5. Click the appropriate attendance button (**Entrada**)
6. Confirm the attendance marking

### 4.3 Break Management

#### Morning Break Process
1. When break time arrives, workers scan their QR codes
2. Click **Salida Receso** (Break Departure) button
3. System records break departure time
4. Worker leaves for scheduled break

#### Break Return Process
1. After break, workers scan their QR codes again
2. Click **Regreso Receso** (Break Return) button
3. System records break return time
4. Worker resumes work activities

### 4.4 End of Day Process

#### Worker Exit Process
1. At end of work day, workers scan their QR codes
2. Click **Salida Obra** (Site Exit) button
3. **Hours Extra Prompt** (if applicable):
   - If worker is leaving later than scheduled exit time
   - System prompts for hours extra confirmation
   - Enter the number of extra hours worked
   - Click **Confirmar** (Confirm)
4. System records final exit time and total hours worked

### 4.5 Daily Review

#### Check Attendance Status
1. Navigate to **Dashboard** (Panel de Control)
2. Review the **Asistencia de Hoy** (Today's Attendance) list
3. Check the **¿Quién está en obra ahora?** (Who's on site now) panel
4. Verify all expected workers have completed their attendance markings

#### Review Alerts
1. Check the **Alertas Recientes** (Recent Alerts) section
2. Address any attendance anomalies or issues
3. Mark alerts as reviewed when resolved

## 5. Attendance Marking Methods

### 5.1 QR Code Scanning (Primary Method)

#### Advantages
- Fastest method (2-3 seconds per worker)
- Reduces human error
- Provides instant worker verification
- Works well for high-volume periods

#### Process Details
1. **Camera Activation**: Click **Iniciar Cámara** (Start Camera)
2. **QR Recognition**: System automatically detects and reads QR codes
3. **Worker Display**: Shows worker photo, name, ID, and position
4. **Action Selection**: Four attendance buttons available:
   - 🟢 **Entrada** (Entry) - Green button
   - 🟡 **Salida Receso** (Break Departure) - Amber button  
   - 🔵 **Regreso Receso** (Break Return) - Blue button
   - 🔴 **Salida Obra** (Site Exit) - Red button
5. **Confirmation**: Visual, audio, and haptic feedback

#### Troubleshooting QR Scanning
- **QR Not Recognized**: Ensure proper lighting and distance
- **Camera Not Working**: Check browser permissions
- **Slow Recognition**: Clean the QR code or worker ID card
- **Multiple QR Codes Detected**: Ensure only one QR code is in frame

### 5.2 Manual Marking (Backup Method)

#### When to Use Manual Marking
- QR code card is damaged or lost
- Camera is not functioning
- Worker forgot their ID card
- System testing and verification

#### Process Details
1. **Worker Search**: Type name or ID in search field
2. **Autocomplete Selection**: System suggests matching workers
3. **Worker Display**: Shows selected worker information
4. **Attendance Marking**: Same four-button interface as QR scanning
5. **Confirmation**: Similar feedback mechanisms

#### Search Techniques
- **Name Search**: Type full or partial name
- **ID Search**: Enter DPI/CUI number
- **Position Search**: Type job position
- **Combined Search**: Use multiple criteria for filtering

### 5.3 Offline Mode Operation

#### Automatic Offline Activation
- System automatically switches to offline mode when internet is unavailable
- Connection status indicator shows red dot
- **Offline queue** stores attendance markings locally

#### Offline Attendance Process
1. Continue normal attendance marking procedures
2. System stores each marking in local queue
3. Sync indicator shows pending queue count
4. **"Pendiente(s)"** (Pending) status appears in top bar

#### Manual Sync Process
1. When internet connection is restored
2. Click **Sincronizar** (Sync) button in top bar
3. System automatically uploads queued attendance markings
4. Success message shows number of synced records
5. Failed items remain in queue for retry

## 6. GPS Verification Process

### 6.1 GPS Configuration Overview

#### Geofence Concept
- **Center Point**: Work site coordinates (latitude/longitude)
- **Radius**: Maximum allowed distance from center (in meters)
- **Verification**: System checks if worker is within allowed area

#### Configuration Options
- **GPS Enabled**: Capture location with each attendance marking
- **GPS Required**: Block attendance if location cannot be verified
- **Geofence Radius**: Set distance tolerance (default: 200 meters)

### 6.2 Location Capture Process

#### Automatic Location Capture
1. When attendance button is clicked, system requests GPS location
2. Device GPS captures current coordinates
3. System calculates distance from work site center
4. Location data is stored with attendance record

#### Location Verification States
- **Inside Geofence**: ✅ Worker is within allowed area
- **Outside Geofence**: ⚠️ Worker is outside allowed area
- **Location Unavailable**: ❌ GPS could not determine location

### 6.3 Outside Geofence Handling

#### Warning System
1. If worker is outside geofence radius
2. System displays warning with distance information
3. Shows message: "Estás a X metros del sitio de obra (Y metros permitido)"
4. Prompts for confirmation: "¿Deseas registrar la marcación de todas formas?"

#### Administrator Options
- **Allow Marking**: Permit attendance despite location
- **Block Marking**: Require worker to move within geofence
- **Investigate**: Follow up with worker about location discrepancy

### 6.4 GPS Troubleshooting

#### Common GPS Issues
- **Permission Denied**: User denied location access
- **Timeout**: GPS took too long to acquire location
- **Low Accuracy**: GPS coordinates are imprecise
- **Indoor Location**: GPS signal weak inside buildings

#### Solutions
- **Check Permissions**: Ensure location permissions are granted
- **Move Outside**: Go near windows or outside for better GPS signal
- **Increase Timeout**: Adjust GPS timeout settings in configuration
- **Disable GPS**: Temporarily disable GPS requirement if consistently failing

## 7. Emergency Procedures

### 7.1 System Failure Scenarios

#### Complete System Outage
1. **Immediate Action**: Switch to paper backup system
2. **Documentation**: Record attendance manually on paper forms
3. **Data Entry**: When system recovers, manually enter attendance data
4. **Verification**: Cross-check paper records with system once operational

#### Internet Connection Loss
1. **Continue Operations**: System works in offline mode
2. **Monitor Queue**: Watch offline queue count in top bar
3. **Plan Sync**: Schedule sync when connection is restored
4. **Data Safety**: Local storage ensures data is not lost

#### Device Failure
1. **Backup Device**: Have secondary device available with system access
2. **Cloud Access**: System can be accessed from any device with browser
3. **Data Recovery**: All data is stored in Google Sheets, not on device
4. **Quick Setup**: New device can be configured in minutes

### 7.2 Worker Emergency Procedures

#### Lost QR Code Card
1. **Immediate**: Use manual marking method
2. **Temporary**: Issue paper ID with worker information
3. **Replacement**: Generate new QR code card in system
4. **Update**: Distribute new card to worker

#### Worker Dispute
1. **Verify Records**: Check attendance history and timestamps
2. **GPS Evidence**: Review location data if GPS was enabled
3. **System Logs**: Check system logs for any errors or anomalies
4. **Resolution**: Document resolution and update records if needed

#### Injury or Emergency
1. **Priority**: Worker safety takes precedence over attendance
2. **Documentation**: Note emergency in attendance records if relevant
3. **Follow-up**: Update attendance status once situation is resolved
4. **Report**: Document any attendance impacts from emergency

## 8. Troubleshooting

### 8.1 Common Issues and Solutions

#### Camera Not Working
**Problem**: QR scanner cannot access camera  
**Causes**: Browser permissions, hardware issue, app conflict  
**Solutions**:
- Check browser camera permissions
- Try different browser
- Restart device
- Close other apps using camera
- Check if camera works in other applications

#### GPS Not Functioning
**Problem**: Location verification fails consistently  
**Causes**: Location permissions disabled, GPS hardware issue, indoor location  
**Solutions**:
- Enable location services in device settings
- Grant browser location permissions
- Move near windows or outside
- Disable GPS requirement temporarily
- Check if GPS works in other applications

#### Sync Failures
**Problem**: Attendance markings not syncing to Google Sheets  
**Causes**: Internet connection, Google Apps Script URL incorrect, API quota exceeded  
**Solutions**:
- Check internet connection
- Verify Google Apps Script URL is correct
- Test connection in Settings
- Check Google Sheets quota limits
- Manually trigger sync when connection is stable

**Problem**: Connection ping succeeds but data reads fail with `getActiveSpreadsheet()` or `Cannot read properties of null`
**Cause**: The Apps Script deployment is using an older backend or is not linked to a spreadsheet.
**Solutions**:
- Update/redeploy the current `gas/Code.gs` version.
- Click **Preparar Google Sheets automáticamente** in the assistant.
- Confirm that the Web App executes as the owner and is accessible to anyone with the link.

#### QR Code Not Recognized
**Problem**: System cannot read worker QR code  
**Causes**: Damaged QR code, poor lighting, camera focus, wrong QR format  
**Solutions**:
- Ensure proper lighting
- Clean QR code card
- Adjust camera distance (15-20cm optimal)
- Check if QR code is damaged or faded
- Use manual marking as backup
- Regenerate QR code if damaged

#### Slow Performance
**Problem**: System responds slowly to actions  
**Causes**: Large dataset, slow internet connection, device performance  
**Solutions**:
- Clear browser cache
- Close other browser tabs
- Check internet connection speed
- Reduce dataset size if possible
- Use more powerful device if available

### 8.2 Error Messages Explained

#### Connection Errors
- **"URL de Google Apps Script no configurada"**: Setup required in Settings
- **"Error de conexión"**: Internet or server issue
- **"Tiempo de espera agotado"**: Request timeout, try again

#### Attendance Errors
- **"Trabajador no encontrado"**: QR code doesn't match any worker in system
- **"Marcación no registrada"**: System error, try again
- **"Fuera del área permitida"**: GPS verification failed

#### GPS Errors
- **"Permiso de ubicación denegado"**: Location permission required
- **"Ubicación no disponible"**: GPS cannot determine location
- **"Tiempo de espera de ubicación agotado"**: GPS timeout
